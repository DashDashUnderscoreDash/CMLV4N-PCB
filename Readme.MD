# **CMLV4N**

CMLV4N is an STM32 12u V4N style PCB with leafspring tadpole mounting featuring forced Cherry ML support

The goal of this PCB is to have a 40% keyboard that uses Cherry ML switches harvested from a Cherry G84-4100

Due to the uneven u sizing on Cherry ML the enter key does not fill that entire area. This is a compromise that needed to be made to make the layout work

Available at [Dashkeebs](https://dashkeebs.bigcartel.com/product/cmlv4n-pcb)

### In this repo you will find:
```
- Layout options
- Images of PCB - Front only for now
- Firmware
- STEP model of PCB
- Edgecuts of PCB
```
